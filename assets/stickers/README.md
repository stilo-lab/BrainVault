# SAB Trading-Sticker

371 lokal erzeugte PNGs, jeweils 320 × 320 Pixel und unter 512 KiB:

- 355 Secret-Brainrots
- 6 OG-Brainrots

Alle 361 Brainrot-Motive dieses Pakets verwenden das primäre Bild des zugehörigen Wiki-Artikels. `catalog.json` ordnet die Dateinamen den Namen, Seltenheiten, Artikeln und Bildquellen zu. Stand: 2. November 2026. Kataloggrundlage: [Secret](https://stealabrainrot.wiki/wiki/secret/) und [OG](https://stealabrainrot.wiki/wiki/og/). Die Eingruppierung folgt der Community-Wiki.

Im Bot: `/sticker liste`, `/sticker senden`, `/sticker installieren` oder `/sticker basispaket`. Weitere Hinweise in `TRADING_STICKERS.md` im Hauptverzeichnis. Discord begrenzt native Server-Stickerplätze; alle PNGs bleiben über den Bot als Bilder nutzbar.
